开始一次恢复
选择 ZIP、Word、Excel、PowerPoint 或 PDF，分析后确认算法与 ZIP 验证项。常见打开密码可直接提取；编辑保护、证书加密与部分旧格式不在此范围。RAR、7z、ZIP64 等可先用外部工具提取哈希，再导入并确认算法编号。
原始压缩包或文档不能直接作为 Hashcat 的哈希文件。完整命令里的目标应填写分析后生成的 target.hash。找到密码后，请用原软件打开验证。


选择与组合策略
知道姓名和生日：先生成线索字典。知道长度与字符：使用规律枚举。不确定：先试内置小字典。中文常见密码、汉字词语与拼音是不同词表，可根据线索补充。
在确认计划页添加另一种策略，按需要上移、下移或删除。例如先试 4 位数字，再试 4 位英文字母，最后跑自己的字典。每阶段耗尽或到达上限后继续；找到全部目标便停止。时间上限不含初始化，达到上限不等于范围已跑完。


掩码速查
每个占位符限定一个字节位置。中文请优先写入 UTF-8 字典，避免把一个汉字当成一位。固定问号写成 ??；内置符号 ?s 包含空格。
写法范围 / 示例
?d数字 0–9
?l / ?u小写 / 大写英文字母
?s / ?a符号 / 英文可打印字符
?1 … ?8引用你定义的字符集
CTF?d?d?d?d!固定前缀 + 四位数字 + 固定后缀
-1 ?l?u?d · ?1?1?1?1四位大小写字母或数字
界面中的最短与最长长度只对应未知部分。每种长度单独生成阶段，固定后缀不会被截掉。默认概率排序与设备并行会改变观察到的尝试顺序。


字典与规则
字典每行一个候选，按原样保留大小写与空格。规则会变形每个词，例如变大写或追加数字。内置轻量规则适合先小范围尝试；大规则集可能让工作量成倍增长。
多个 -r 默认逐层组合，数量可能相乘；勾选规则合并则按一份列表处理。双字典 -a 1 会拼接两个字典中的词。-a 6 在字典词后添加掩码，-a 7 在前面添加。8.0 的 -a 12 可用 ?w 将字典词嵌入掩码。


读懂进度
已处理检查 / 当前阶段总量来自引擎。处理量可能包含长度不符等拒绝项；多盐验证和不同阶段还会重复计数，因此不能等同于已试过多少个不同密码。大整数会完整保留。
基础分配位置是可恢复的基础工作位置，规则、放大器及设备正在执行的批次另计，并不是字典第几行。来源队列表示正在使用的字典或掩码文件序号。
最近候选窗口显示设备最近抽样批次的起止候选，不是逐个密码的实时流水。8.0 可能每次只抽样一个设备；没有报告时会明确等待。最多保存 20 次快照，可导出，任务记录也能回看。未知总量不显示虚构百分比。
预计完成来自 Hashcat，只对应当前工作范围，会随速度波动。原始日志保留引擎输出，便于核对。


并行与性能
Hashcat 本身使用大量并行计算。设备编号 -d 1,2 可让一个进程协同使用多设备；OpenCL 设备类型 -D 1,2 可纳入 CPU 与 GPU，但前提是安装相应运行时并能被检测到。增加设备不保证线性提速。
默认自动调优通常合适。-T 是 GPU / 计算内核线程设置，不是 CPU 线程滑块；-n、-u 会影响批次大小。-Y 为每个设备创建虚拟实例，可能占用更多显存，适合有经验用户做对照测试。多个进程争用同一 GPU 可能更慢。
Hashcat 8 忽略 -w。本界面不提供由它实现的负载档位。-O 可能提速但限制密码长度。Word / PDF 的高迭代加密常比普通 MD5 慢很多，先缩小候选范围通常更有效。


搭配命令
进入完整命令，可选择方式、哈希文件、字典与掩码。生成参数只填入编辑器，检查后点击执行。设备、规则、字符集与内核设置沿用当前进阶选项。算法 -m 与恢复方式 -a 是两回事，ZIP 和 Office 的 -m 以实际分析结果为准。
["-m", "0", "-a", "3", "--runtime", "60", "D:/case/target.hash", "?d?d?d?d"]
示例仅适用于 MD5。界面将 JSON 中的每一项作为独立参数传给程序，不经过命令行解释器。复制命令会按当前系统处理引号，含空格的路径也可以使用。
PCFG -a 4 会先生成较可能的候选，但没有线索时范围仍可能巨大。8.0 的 Table、Feed、Hash Recipe 等可在完整命令中使用；内置完整帮助会从当前引擎加载。


停止与数据
停止会结束进程，最近检查点后的工作可能重跑。任务记录中只有实际存在的检查点才可继续，沿用原来的策略与时间限制。复用完整计划会新建任务；修改线索也会新建范围。
Windows 使用 WebView2，macOS 使用系统 WebKit，Linux 使用 WebKitGTK 4.1。macOS 和 Linux 默认保存到用户数据目录；Linux 可用 portable.flag 启用便携工作区。任务、候选、结果与日志可能包含明文密码，均在本机处理。
依据随包 Hashcat 8.0.0 帮助、官方掩码文档和版本说明整理；详细参数请到完整命令加载帮助。
